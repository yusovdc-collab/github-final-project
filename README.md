# Simple Interest Calculator

This project is a simple interest calculator created using Bash scripting.

## Description
The calculator allows users to calculate simple interest by entering a principal amount, interest rate, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Features
- Accepts user input
- Calculates simple interest
- Displays the result

## How to Use
1. Download the simple-interest.sh file.
2. Open a terminal.
3. Run the script using Bash.
4. Enter the principal, interest rate, and time period.
